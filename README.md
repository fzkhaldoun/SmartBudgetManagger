# SmartBudgetManagger
A project for managing Budget.
SmartBudget Manager  :
An excel-based management tool designed for business owners and small enterprises to track the monthly incomes and daily expenses , alerts when budget exceeded and visualization . 
Features
Task Logging: Record monthly income and expenses.
Expenses Categorization: Compare spending with specified categories and see the limit of each entry
Automated Calculation & Visualization: Calculate the total monthly balance using SUM and generate a chart that explains the results.
Budget Exceeding Alerts: Send alerts after comparing the budget and expenses when spending exceeds the limit.
 System Requirements
To run SmartBudget Manager, your computer must meet the following requirements:
Software: Microsoft Excel 2016, 2019, 2021, or Microsoft 365.
File Compatibility: .xlsx format enabled.
Quick Start Guide
1.Download SmartBudget_Manager.xlsx to your local desktop folder.
2.Double-click on the Excel file.
3.Navigate to Transactions and adjust expenses/income, and adjust categories if needed.
4. Go to Dashboard to see results from remaining expenses, alerts, and the updated chart.
Important Usage Rules
I.Do not delete cells, rows, or columns.
II.Do not modify formulas manually.
